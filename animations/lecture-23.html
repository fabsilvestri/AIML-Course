Vision transformers and multimodal retrieval

An image turned into a sequence one patch at a time: the patch size, the token count it implies, and what the positional encoding is for. Press Step to advance one unit and read what happened; press Play to let it run.

All data on this page is synthetic, generated in your browser from a fixed seed, so Reset always gives back the same picture. The embeddings are random or hand-built vectors, not the output of a trained model.

1An image as a sequence

A synthetic 224 × 224 image is cut into $P \times P$ patches. Each step takes the next patch, flattens its $3P^2$ pixel values into a vector $\mathbf{x}_i$, projects it linearly to a token $\mathbf{z}_i = \mathbf{E}\mathbf{x}_i$, adds the position vector $\mathbf{p}_i$, and appends the result to the sequence after the [CLS] token. Change $P$ and watch the sequence length, and the cost of attention, move.

The mathematics

An $H \times W$ image in patches of $P \times P$ gives

$$N = \frac{H}{P}\cdot\frac{W}{P}, \qquad \mathbf{x}_i \in \mathbb{R}^{3P^2},$$ $$\mathbf{t}_i = \mathbf{E}\,\mathbf{x}_i + \mathbf{p}_i .$$

Self-attention compares every token with every token, so one head in one layer computes $(N+1)^2$ scores. With $N \propto P^{-2}$ that is roughly $\propto P^{-4}$: halving $P$ multiplies the cost by about 16. Here $\mathbf{E}$ maps to a toy $d_{\text{model}} = 8$ so the tokens fit on screen; ViT-Base uses 768.

Attention without positions is a weighted average over a set: for the [CLS] query $\mathbf{q}$, $\sum_j \operatorname{softmax}_j(\mathbf{q}^{\top}\mathbf{k}_j/\sqrt{d})\,\mathbf{v}_j$ does not depend on the order of the $j$. Only $\mathbf{p}_i$ tells the model where a patch was.

Watch for
  • The flattened strip is the patch read row by row. Nothing in $\mathbf{x}_i$ records that two values were vertical neighbours — the locality a convolution assumes is gone at this step.
  • The cost plot is a straight line of slope about $-4$ on log–log axes: the sequence length goes as $P^{-2}$ and attention squares it.
  • The side panel's last line: shuffle the patches with positions switched off and the [CLS] output does not change at all.
Try this
  1. Set $P = 8$: 784 patches and 616,225 attention scores per head per layer, about 15.9 times the cost at $P = 16$.
  2. Tick Shuffle the patches, then untick Add positions. The image is scrambled, yet the [CLS] change reads 0.
  3. Set $P = 56$: only 16 tokens, cheap — but each token must summarise a quarter of the house.
